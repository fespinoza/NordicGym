# NordicGYM

This is a sample app for my conference talk [Snapshot Testing in Practice: Predictable and Reliable SwiftUI Views](https://craftingswift.dev/talks/snapshot-testing)

It shows how I setup snapshot testing for a project.

Some of the UI doesn't handle all the cases it should and I left them like that
to show how snapshot tests help you detect those issues. The solution is left
to the reader ;)
